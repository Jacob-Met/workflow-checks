      How to read this demonstration

      Capacity follows the source ledger. Completed visits consume approved capacity first; scheduled visits follow in date order. Authorization start and end dates are inclusive. A pending record does not supply approved capacity.

      Priority is an administrative rule label. P1, P2 and P3 come from the existing synthetic payer table and rule engine. They are not clinical urgency, a guarantee of coverage or instructions to change patient care.

      Evidence remains traceable. File and row references identify the original repository sample. A “scenario edited” label marks any row changed here. No original file is rewritten.
