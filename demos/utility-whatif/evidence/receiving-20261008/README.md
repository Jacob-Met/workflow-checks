## Evidence sequence and corrections

`native-model-install.log` preserves the first native model and installer run.
`browser-first.json` preserves the first browser failure, and
`browser-first-harness.mjs` preserves that exact harness. Eleven groups failed
because the harness expected title-case rendered labels while CSS renders them
uppercase. The correction changed those expectations; it did not change product
behavior. `browser-corrected.json` records the subsequent passing run.

Independent review then found imprecise month-assignment wording. The actual
algorithm already chose the latest month among months tied for the most days.
For 2026-01-01 through 2026-04-15, January and March each have 31 days, so March
wins even though April is the ending month. The UI and README were clarified,
three long-period cases were added, and the final runtime was installed and
received again. `native-final.log` and `browser-final.json` qualify those final
bytes; `desktop.png` and `phone.png` show that final installation.

`independent-production-review.json` records the bounded acceptance. The reviewer
read the producer's suites and exact receipt rather than claiming to rerun them.
`source-provenance.json` records the original source, fixture and evidence hashes.

## Reproduce

From `demos/utility-whatif/` with Python 3.10+ and Node:

```sh
python3 build_fixture.py --check
node --test tests/model.test.mjs
python3 -m unittest discover -s tests -p 'install_test.py'
```

The optional browser harness uses existing Chrome and Playwright installations.
Set `UTILITY_PLAYWRIGHT` to the existing Playwright module, `UTILITY_CHROME` to
the existing Chrome executable, `UTILITY_INSTALL_DIR` to the installed five-file
target, and `UTILITY_EVIDENCE` to an absent output directory; then run
`node tests/browser.mjs`. It creates a bounded ephemeral loopback server and fresh
contexts and closes them afterward. Nothing is listening persistently.

Producer runtimes were Python 3.12/Node 24 locally and Python 3.13.7/Node 26.3.0
plus Chrome 154.0.8037.98 on the Mac. The broader upstream pytest suite was not
available in the local partial source environment (`No module named pytest`).
This record claims the focused checks above; repository CI is a separate gate.

The producer's local Git history is explicitly a partial source snapshot of
